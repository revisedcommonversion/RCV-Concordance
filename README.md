# A concordance for the Holy Bible: Revised Common Version.

## Introduction

This concordance was inspired by a reader's comment who said he was mostly joking. I took it as a challenge. The challenge was to generate a full concordance of the text of the RCV using the Python programming language and Linux commands (mainly `grep` and `sed`), with the files formatted in AsciiDoc. The result is what you see here in this code repository. I hope you find this concordance to be useful in your studies.
